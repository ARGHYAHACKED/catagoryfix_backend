## Keyword Cannibalization Prevention Rules

1. **Exact One Primary Intent**: No two pages target the same primary keyword.
2. **Distinct Value Propositions**:
   - `/shopify-csv-converter`: For converting an arbitrary file to Shopify format.
   - `/shopify-csv-validator`: For auditing an existing Shopify CSV file for syntax errors.
   - `/supplier-csv-to-shopify`: For mapping supplier dropship feeds and applying wholesale markups.
   - `/excel-to-shopify`: Specifically for parsing native `.xlsx` workbooks.
